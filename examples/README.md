# Fictional examples

These examples use invented content and generic paths. They demonstrate the workflow without containing a real vault, conversation, or personal configuration.

- `existing-category.md` represents a long-lived category document before an update.
- `sample-preview.md` shows the default review-mode output before a write.
- `sample-direct-write.md` shows an explicit direct-write request and the receipt reported after verification.

The examples are human-facing documentation. They are not required by the installed Skill.
